# Tensura Prestige Fix (`tensura_prestige_fix`)

## Requirements
- **Minecraft:** `1.21.1`
- **Mod Loader:** `NeoForge 21.1.x`
- **Java:** `Java 21`

## Installation
1. Download [`releases/tensura-prestige-fix-1.0.0.jar`](releases/tensura-prestige-fix-1.0.0.jar).
2. Place `tensura-prestige-fix-1.0.0.jar` into the `mods/` folder of your **Server** (or **Client** for Singleplayer / LAN).
   - **Multiplayer Server:** Installing on the server `mods/` folder is sufficient; players do not need to install this mod on their client to join. It can also be safely included in both server and client modpacks.
3. Restart the server (or game) to load the mod and generate `config/tensura_prestige_fix-common.toml`.
